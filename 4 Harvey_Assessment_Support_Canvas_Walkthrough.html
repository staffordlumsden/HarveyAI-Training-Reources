Local design ruleThe academic marker makes the substantive judgement before Harvey is used for evidence mapping, feedback wording, moderation preparation or cohort analysis. This is an educational-governance boundary, not a technical limitation of Harvey.
1

Design for valid evidence before asking Harvey to draft.

Start with the capability the assessment must elicit, the evidence students must produce and the conditions under which that evidence will be judged.

Use Harvey to critique and refine an educator-authored assessment design—not to generate an assessment in a vacuum. The sequence is capability → evidence → task → criteria → standards → stress-test → educator approval.

Purpose

Define the capability

Legal knowledge, statutory interpretation, research, legal reasoning, policy analysis, writing, oral advocacy, professional judgement or reflection.

Evidence

Make performance observable

State what successful performance looks like and what must be visible in the submission or observed task.

Conditions

Specify the assessment context

Outcomes, AQF/cohort level, weighting, time or word limit, permitted resources, AI-use conditions, format and policy constraints.

Assessment-design prompt

Quality checks for criteria and standards
CheckQuestion
DistinctDoes each criterion judge a genuinely different aspect of performance rather than double-counting the same quality?
AssessableCan a marker make the judgement from evidence actually available in the submission or observed performance?
AlignedDoes the criterion represent the intended learning outcome or capability rather than an incidental feature of the task?
DiscriminatingDo grade-band standards describe meaningful qualitative differences rather than “excellent / very good / good”?
UsableCan markers apply the criteria consistently within realistic marking time and moderation arrangements?
ReadableCan students understand what quality looks like without the rubric becoming a hidden second set of task instructions?
AI-awareWhere AI is permitted, do the task and criteria still allow genuine student capability to be demonstrated and judged?
!
Stress-test before release

Ask how a capable student could satisfy the wording without demonstrating the intended capability, and how a student could reasonably misread the task or criterion. Revise in educator voice for legal accuracy, policy fit, accessibility and realistic marking workload.

2

Make the substantive academic judgement first.

This guide does not treat Harvey as a marker. The marker reads the work and records the criterion-level judgement before using Harvey for bounded support.

!
Human-first marking sequence

A disagreement between Harvey-assisted analysis and the marker’s reading is a prompt to re-read the evidence, not a reason to defer to the model. Final marks, grades and moderation outcomes remain human decisions.

1
Confirm permitted data use

Before uploading student work, check the University data-classification, privacy, assessment and AI-use rules for the configured Harvey environment. If permission is unclear, do not upload.

2
Minimise identifying data

Remove names, student IDs, email addresses, coversheets, comments and unnecessary metadata unless retention is expressly authorised. Use neutral or pseudonymous labels where permitted.

3
Read and judge independently

Record the marker’s own criterion-level judgement or notes before asking Harvey to assist.

4
Provide the actual marking frame

Supply the assessment task, rubric or criteria, grade standards and any authorised marking or feedback conventions. Do not ask Harvey to infer them.

5
Choose one bounded support task

Map evidence to criteria; test whether a draft comment is supported; identify omissions; draft criterion-linked feedback; create feed-forward suggestions; or prepare moderation questions.

i
Security is not permission

Harvey’s enterprise security controls do not determine whether particular student data may be processed for a specific University purpose. Product security and local governance are separate questions.

3

Use Harvey for evidence mapping and feedback drafting after judgement.

Keep observations traceable to the submission and criteria. Draft feedback for educator review rather than allowing the tool to change the academic judgement.

Ground

Map evidence

Ask for relevant passages, missing or underdeveloped evidence, apparent performance and matters requiring human moderation.

Compare

Test consistency

Use the output to organise or challenge the marker’s reasoning. Re-read where there is disagreement.

Draft

Write for action

For each criterion: what worked, what limited the performance and one actionable next step.

A. Evidence-to-criteria map after human marking
Instruction: Using only the supplied de-identified submission, assessment task and rubric, create an evidence map for educator review. The marker has already made the substantive academic judgement.

For each criterion, provide:
1. Relevant evidence from the submission.
2. Evidence that may be missing or underdeveloped.
3. A concise description of the apparent performance.
4. Any point that requires human moderation.

Constraints:
- Do not assign a mark or grade.
- Do not infer knowledge or reasoning that is not evidenced in the submission.
- Do not identify the student.
- Distinguish absence of evidence from evidence of absence.

Verification:
Where Harvey provides source links or citations, identify the supporting passage. Flag any statement that cannot be traced confidently to the submission.
B. Draft criterion-linked feedback
Instruction: Using the marker’s supplied criterion-level judgement and the verified evidence map, draft feedback for educator review.

Structure: For each relevant criterion:
(a) what the response did effectively;
(b) what limited the performance;
(c) one actionable next step.

Keep the language specific to the work rather than generic praise or deficit labels.

Limits:
- Do not change the marker’s academic judgement.
- Do not introduce new criticisms unsupported by the submission.
- Do not mention AI or Harvey unless the educator requests it.

Output:
A concise feedback draft plus a separate “educator check” list of claims requiring re-reading before release.
C. Cohort-level feedback after marking
Instruction: Using only the verified, de-identified evidence supplied across the cohort, identify recurring patterns that would be useful to address in whole-of-cohort feedback.

Provide:
1. Common strengths.
2. Common misunderstandings.
3. Legal reasoning/application issues.
4. Use-of-authority issues.
5. Communication/structure issues.
6. Feed-forward advice.
7. Patterns that may indicate a teaching or task-design issue.

Constraints:
- Do not refer to individual students.
- Do not infer prevalence beyond the documents analysed.
- Do not treat an AI-generated classification as a frequency count until the underlying cells/items have been checked.
✓
Approve student-facing text

Before release, check accuracy, tone, specificity, usefulness, accessibility and consistency with the actual mark. Draft wording remains an educator responsibility.

4

Use Review Tables for structured multi-document analysis.

Current Harvey supports Review Tables both independently from files in Assistant and within Vault. Choose the source context according to the scale, persistence and reuse needs of the corpus.

Build extraction before evaluation. Relatively factual columns such as authorities cited or issues named are easier to verify than evaluative columns such as quality of application. Verify upstream outputs before chaining conditional analysis.

1
Define a narrow analysis purpose

Moderation preparation, common-error analysis, authority-use review, issue-spotting patterns, cohort feedback or assessment redesign.

2
Prepare the permitted file set

Apply data controls and minimise identifiers. Use consistent neutral or pseudonymous labels where permitted.

3
Choose Assistant or Vault

Create an independent Review Table for a bounded analysis, or use Vault where the document set is persistent, large or reused.

4
Design assessment-aligned columns

Avoid generic “summary” columns that collapse multiple judgements into one opaque output.

5
Inspect evidence, reasoning and citations

Click through to source material rather than treating a populated cell as verified. Use editing, comments and verification/activity features where available.

6
Ask over verified table data

Once material cells are checked, use Assistant to query patterns or draft a moderation brief. A Review Table can also be reused as a Knowledge Source.

!
Do not infer prevalence from unchecked cells

A table containing 100 generated classifications is not automatically a valid dataset. Verify classifications before treating counts, frequencies or patterns as evidence.

5

Use generated analysis as one input to human moderation.

Moderation is a judgement-sensitive academic process. Harvey may help surface evidence or possible patterns; academic moderators decide calibration and final outcomes.

Marker calibration

Prepare questions, not verdicts

Use bounded analysis to identify where markers may need to compare evidence, interpret a criterion or discuss the treatment of a borderline performance.

Cohort patterns

Translate verified evidence into teaching action

Common strengths, errors or reasoning patterns can inform whole-of-cohort feedback, additional teaching and future assessment redesign once the underlying evidence is checked.

i
Keep moderation and student feedback separate

A useful moderation table may contain judgement-sensitive notes that should never be released directly to students. Share or export only the output appropriate to the intended audience.

6

Verify, document and use the evidence to improve assessment.

The defensible end-to-end sequence is design for valid evidence → make the academic judgement → use Harvey for bounded support → verify evidence and wording → moderate with humans → analyse verified patterns → improve teaching and assessment.

Assessment-support governance record

Current product-currency corrections reflected in this page
  • Review Tables: no longer require Vault; independent Review Tables can be created from files in Assistant.
  • Assistant / Vault distinction: choose according to scale and persistence rather than treating Vault as the default assessment workspace.
  • Review Table citations: sentence-level citations and reasoning support validation, but material cells still require source checking.
  • Review features: current capabilities include comments, editing/verification/activity tracking and conditional columns that can reference earlier outputs.
  • Reuse: a Review Table can be used as a Knowledge Source for later Harvey work.
  • Data governance: product security does not itself determine whether student PII or confidential material may be processed.
  • Human-first marking: retained as a local educational-governance choice, not presented as a technical limitation of Harvey.
✓
Educational-design basis

The workflow is consistent with constructive alignment, standards-based judgement and feedback-for-learning principles: assessment should elicit intended outcomes; criteria should make quality judgements explicit; and feedback should support improvement in future performance.
